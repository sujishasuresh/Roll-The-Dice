# Roll the Dice 🎲

A simple Python console application that simulates rolling dice.

## Features
- Roll one or more dice
- Generates random values between 1 and 6
- Tracks how many successful rolls occur during the session
- Handles invalid inputs gracefully
- Allows the user to continue rolling or quit

## Technologies Used
- Python
- random module

## How to Run

```bash
python roll_the_dice.py
```

## Sample Output

```
Roll the dice? (y/n): y
How many dice do you want to roll? : 3
(4, 1, 6)
You have rolled the dice 1 times

Roll the dice? (y/n): n
Thanks for playing!
```
